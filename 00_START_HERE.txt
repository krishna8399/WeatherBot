Welcome! This is a conversational AI weather assistant built with Rasa.
Follow the 3 steps below to run the bot.

───────────────────────────────────────────────────────────────────
STEP 1: Run Diagnostic Test (Recommended)
───────────────────────────────────────────────────────────────────

Open a terminal in this folder and run:

    python test_setup.py

This checks: Python version, dependencies, API key, API connection, model.
Expected output: "✓ All checks passed!"

If you see "403 Forbidden" or "401 Unauthorized" error:
  → The hardcoded API key may have hit usage limits
  → Get a new FREE key (takes 2 minutes): 
    https://www.weatherapi.com/signup.aspx
  → Open actions/actions.py and replace the WEATHERAPI_KEY value
  → Save the file and restart: rasa run actions

───────────────────────────────────────────────────────────────────
STEP 2: Install Dependencies
───────────────────────────────────────────────────────────────────

    pip install -r requirements.txt

(Takes 2-3 minutes)

───────────────────────────────────────────────────────────────────
STEP 3: Run the Bot
───────────────────────────────────────────────────────────────────

You need TWO terminal windows:

TERMINAL 1 - Start the actions server:
    rasa run actions

Wait until you see: "Action endpoint is up and running"

TERMINAL 2 - Start the chatbot:
    rasa shell

Now chat with the bot! Try these:
  • "What's the weather in London?"
  • "Will it rain today?"
  • "Should I carry an umbrella?"
  • "What should I wear?"
  • "What's the humidity in Paris?"

Type "bye" or "/stop" to exit.

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: "No module named 'rasa'"
Solution: Run: pip install -r requirements.txt

Problem: "Could not connect to action server"
Solution: Make sure Terminal 1 (rasa run actions) is running first
          and shows "Action endpoint is up"

Problem: "403 Forbidden" or "401 Unauthorized" 
Solution: 
  1. Get new key: https://www.weatherapi.com/signup.aspx
  2. Open actions/actions.py in text editor
  3. Replace WEATHERAPI_KEY = "..." with your new key
  4. Save file
  5. Stop and restart: rasa run actions

Problem: Bot responses are slow
Solution: This is normal - the bot fetches real weather data from API

Problem: Bot says "I don't understand"
Solution: Try example questions from Step 3 above
          The bot is trained on weather-related queries only
