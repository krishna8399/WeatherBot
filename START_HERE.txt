│ STEP 1: Set Up API Key (REQUIRED - Takes 30 seconds)          │
└────────────────────────────────────────────────────────────────┘

   Windows Users:
   ──────────────
   Double-click: setup_api_key.bat
   
   When prompted, press Enter to use the evaluation key.
   Close and reopen your terminal after running.

   Linux/Mac Users:
   ────────────────
   Run in terminal:
     chmod +x setup_api_key.sh
     ./setup_api_key.sh
     source ~/.bashrc  (or ~/.zshrc)

┌────────────────────────────────────────────────────────────────┐
│ ⚠️  Troubleshooting                                            │
└────────────────────────────────────────────────────────────────┘

   Error: "WeatherAPI key not set"
   ───────────────────────────────
   → You skipped Step 1. Run setup_api_key.bat (or .sh)
   → Verify with: echo %WEATHERAPI_KEY%  (Windows)
                 echo $WEATHERAPI_KEY   (Linux/Mac)

   Error: "No module named 'actions'"
   ──────────────────────────────────
   → Set PYTHONPATH to project root:
     Windows: set PYTHONPATH=%CD%
     Linux/Mac: export PYTHONPATH=$(pwd)

   Error: "No module named 'rasa'"
   ───────────────────────────────
   → Run: pip install -r requirements.txt
